# 🚌 퇴근 스쿨버스

**엘리베이터 도착 전까지 칼퇴해라!**

18시, 15층. 팀장 시야를 피해 퇴근 준비를 끝내고 퇴근 마감 시간 전에 엘리베이터 앞에 서면 문이 열린다.
브라우저에서 바로 돌아가는 탑다운 픽셀 스텔스 게임. 빌드 과정 없는 순수 HTML + Canvas.

## 플레이

| 조작 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| `Shift` (홀드) | 살금살금 — 조용하고 들킴 게이지가 절반 속도로 찬다 |
| 할 일 지점에서 가만히 | 처리 시작 |
| 타이핑 후 `Enter` | 슬랙 답장 / git commit 전송 |
| `M` | 음소거 |
| `R` | 현재 레벨 재시작 |

### 개발/테스트용 URL 파라미터

게임 화면에는 노출하지 않지만 주소 뒤에 붙이면 동작한다 (`?day` 로 2 이상을 지정하면 최고 기록에는 반영되지 않음).

| 파라미터 | 동작 |
|---|---|
| `?day=6` | 해당 레벨부터 시작 (1~99) |
| `?goto=err` | 오류 발생 자리에서 시작 |
| `?goto=sink` | 탕비실 싱크대(설거지)에서 시작 |
| `?goto=cup` | 커피 컵이 놓인 자리에서 시작 |
| `?goto=desk` | 내 자리에서 시작 |
| `?goto=locker` \| `trash` \| `wc` \| `elev` | 사물함 / 쓰레기통 / 화장실 / 엘베 앞 |
| `&bug=0` | 오류 수정 미션의 버그를 고정 (0~11, 생략하면 랜덤) |

`R` 키로 재시작하면 `goto` 지점이 유지되므로 `bug` 번호만 바꿔가며 12종을 빠르게 확인할 수 있다.

브라우저 콘솔에서 쓸 수 있는 훅: `__dbg()` (상태 전체) · `__tp(x,y)` (순간이동) · `__clock(초)` (마감 시간 조작)

## 규칙

- **퇴근 체크리스트**를 다 끝내야 엘베 문이 열린다. 레벨이 오를수록 할 일이 하나씩 늘어난다.
  `💻 노트북 끄기` → `🎒 가방 챙기기` → `⌨️ git commit` → `☕ 커피 버리기` → `🚻 화장실`
- `git commit` 을 하지 않으면 노트북을 끌 수 없다.
- `☕ 커피 버리기` 는 책상 위 컵을 들고 쓰레기통까지 운반해야 하며, 들고 있으면 이동 속도가 느려진다.
- **팀장 시선은 플레이어를 쫓지 않는다.** 정해진 패턴만 반복하니 리듬을 읽고 통과할 것. 레벨이 오르면 변곡점이 2 → 4 → 6 → 8개로 늘고 멈추는 시간이 짧아진다.
- 들키면 즉사가 아니라 **3초 정지**. 그동안 마감 시간은 계속 흐른다.
- 💬 슬랙이 오면 **그 자리에 얼어붙고** 답장을 타이핑해야 풀린다. 제한 시간 내에 못 보내면 팀장이 직접 온다.

## 점수

```
클리어 보너스        레벨 × 500
남은 시간            남은초 × 100
할 일 개수           개수 × 200
⚡ 타이핑 속도        기준시간보다 빠른 만큼 (최대 커밋 600 / 슬랙 450)
🤫 무적발 보너스      +1,000  (한 번도 안 들켰을 때)
```

레벨을 넘겨도 점수는 계속 누적된다. 최고 레벨과 최고 점수는 브라우저에 저장된다.

## 실행

정적 파일이라 `index.html` 을 브라우저로 바로 열어도 되고, 로컬 서버로 열어도 된다.

```bash
python3 -m http.server 8000
# http://localhost:8000/leave-on-time/
```
