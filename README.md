### 개발/테스트용 URL 파라미터

게임 화면에는 노출하지 않지만 주소 뒤에 붙이면 동작한다 (`?day` 로 2 이상을 지정하면 최고 기록에는 반영되지 않음).

| 파라미터 | 동작 |
|---|---|
| `?day=6` | 해당 레벨부터 시작 (1~99) |
| `?goto=err` | 오류 발생 자리에서 시작 |
| `?goto=sink` | 탕비실 싱크대(설거지)에서 시작 |
| `?goto=cup` | 커피 컵이 놓인 자리에서 시작 |
| `?goto=desk` | 내 자리에서 시작 |
| `?goto=locker` \| `trash` \| `wc` \| `elev` | 사물함 / 쓰레기통 / 화장실 / 엘베 앞 |
| `&bug=0` | 오류 수정 미션의 버그를 고정 (0~11, 생략하면 랜덤) |
| `?pack=pm:policy` | 직군·언어 팩 고정 (`dev:js` \| `dev:kotlin` \| `dev:swift` \| `pm:policy`) |

`R` 키로 재시작하면 `goto` 지점이 유지되므로 `bug` 번호만 바꿔가며 12종을 빠르게 확인할 수 있다.

브라우저 콘솔에서 쓸 수 있는 훅: `__dbg()` (상태 전체) · `__tp(x,y)` (순간이동) · `__clock(초)` (마감 시간 조작)

## 직군 · 언어 고르기

시작 화면에서 고른다. **⌨️커밋 / 🚨오류수정 미션의 내용만** 바뀌고 맵·마감시간·NPC는 전부 같다.
같은 시드면 어느 팩에서든 같은 배치가 나온다.

| 고르면 | ⌨️ | 🚨 |
|---|---|---|
| 🟨 JavaScript | `git commit -m "fix typo"` | `consol.log(...)` → 콘솔 에러 보고 오타 한 곳 수정 |
| 🟪 Kotlin | `./gradlew test` | `pritnln(items.size)` → `Unresolved reference` |
| 🟧 Swift | `swift test` | `pirnt(items.count)` → `Cannot find 'pirnt' in scope` |
| 📋 기획자 | `[확정] 쿠폰 정책 v2.1` | 정책 문장 + 제보 → 틀린 곳 한 군데 수정 (한글 입력) |

기획자 🚨 예시 — 정책문이 미리 채워져 있고 **제보만** 온다. 정답은 안 보여준다.

```
정책문   쿠폰은 1만원 이하 주문 시 3천원 할인
제보     CS 제보 — 3만원 주문인데 할인이 안 됩니다. 최소금액 조건이 뒤집혔습니다
```

두 미션은 겨루는 능력이 다르다 — ⌨️는 **정답을 보여주고 손 속도**를, 🚨는 **정답을 숨기고 위치 판단**을 본다.
6초가 지나면 힌트가 뜬다.

## 규칙

- **퇴근 체크리스트**를 다 끝내야 엘베 문이 열린다. 레벨이 오를수록 할 일이 하나씩 늘어난다.
  `💻 노트북 끄기` → `🎒 가방 챙기기` → `⌨️ git commit` → `☕ 커피 버리기` → `🚻 화장실`
- `git commit` 을 하지 않으면 노트북을 끌 수 없다.
- `☕ 커피 버리기` 는 책상 위 컵을 들고 쓰레기통까지 운반해야 하며, 들고 있으면 이동 속도가 느려진다.
- **팀장 시선은 플레이어를 쫓지 않는다.** 정해진 패턴만 반복하니 리듬을 읽고 통과할 것. 레벨이 오르면 변곡점이 2 → 4 → 6 → 8개로 늘고 멈추는 시간이 짧아진다.
- 들키면 즉사가 아니라 **3초 정지**. 그동안 마감 시간은 계속 흐른다.
- 💬 슬랙이 오면 **그 자리에 얼어붙고** 답장을 타이핑해야 풀린다. 제한 시간 내에 못 보내면 팀장이 직접 온다.

## 실행

정적 파일이라 `index.html` 을 브라우저로 바로 열어도 되고, 로컬 서버로 열어도 된다.

```bash
python3 -m http.server 8000
# http://localhost:8000/leave-on-time/
```

## 순위표

**전체 · 🟨JS · 🟪Kotlin · 🟧Swift · 📋기획자** 탭으로 나눠서 본다.
한 사람이 여러 팩을 뛰면 **팩마다 최고 기록이 따로 남는다** — Kotlin 15만점과 기획자 8만점이 각각 집계된다.

「전체」는 pid당 역대 최고점 한 줄이다. 팩 선택이 생기기 전 기록은 그때 콘텐츠가 JS 하나뿐이었으므로 **🟨JS 탭으로 이관**했다.
개발자 탭은 따로 두지 않았다 — 세 언어 탭의 합집합이라 중복이다.

랜덤 닉네임(`야근인턴#e1e` 형태)이 첫 플레이 때 자동 배정되고 브라우저에 저장된다. 헤더의 🎲로 다시 뽑을 수 있다.
개인정보는 저장하지 않는다 — 닉네임은 클라이언트가 만든 랜덤 문자열이고, 서버는 레이트리밋용 IP 해시만 남긴다.

백엔드는 **Cloudflare Workers + D1** (`leaderboard-worker/`). 게임 페이지에는 API 키가 들어가지 않고,
Worker 주소로만 요청한다. 설정과 보안 검증 내역은 [`leaderboard-worker/DEPLOY.md`](leaderboard-worker/DEPLOY.md) 참고.

서버가 꺼져 있거나 오프라인이면 자동으로 이 브라우저에 저장된 기록으로 대체되므로, 순위표 때문에 게임이 멈추지 않는다.

## 시드

맵 배치(내 자리 / 오류 발생 자리 / 커피 자리)는 **시드 기반 난수**로 결정된다. 직군·언어는 여기 영향을 주지 않는다.
같은 시드면 같은 배치가 재현되므로, 데일리 챌린지나 멀티플레이에서 "모두 같은 판"을 만들 수 있다.

```
?seed=kurly     같은 배치 재현
```

거품·효과음 같은 연출은 시드를 쓰지 않는다 (매번 달라야 자연스러움).
